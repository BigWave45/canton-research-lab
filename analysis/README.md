# Executable analysis

The Python modules in this directory implement selected accounting validators, reconciliation models, allocation logic, assurance comparisons and synthetic disclosure experiments.

The corresponding unit tests are in [`tests/`](../tests/). Start with [`REPRODUCIBILITY.md`](../REPRODUCIBILITY.md) for commands and interpretation boundaries.

These modules operate on explicit inputs and constructed records. They do not connect to Canton production systems or independently establish source-measurement completeness.
